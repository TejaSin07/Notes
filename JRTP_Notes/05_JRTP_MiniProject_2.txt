Execution Flow:
===============
1) User will open website home page
	-> Logo display with nav bar
	-> Carousel(banners sliding )
	-> course Images Display
	-> Login button 

2) User Registration
	-> Unique Email validation
	-> temporary password generation
	-> send registration email with temp pwd and unlock link

3) Unlock account
	-> Temporary Pwd validation
	-> Set new password
	-> unlock account

Note : user should unlock account only one time .If user try to unlock account second time application should display message as
"your account already unlocked "


4) Login fuctionality:
	-> unlocked account users only can login
	-> Invalid Credentials Check (error : Invalid Credentials)
	-> Account Status Check (error : your account locked)
	-> LOGIN SUCCESS : Display Dashboard with logged in user performance report

5) Forgot Pwd:
	-> Invalid Email : No account found with given mail
	-> Valid Email : get pwd from DB and send users Pwd to user email


6) Dashboard :
	-> Display logged in user performance report 

7) Add Enquiry :
	-> Add new Enquiry with status as 'New'

8)View Enquiries :
	-> Display enquiries which are added by logged in user
	-> Edit Enquiry to updtae Enquiry Status
	-> Filter Enquiries based on given criteria

9) Logout :
	-> when user click on logout display home page

AJAX (asynchronous java script and xml )
=====
2 type of request

1) synchronous request (whole web page will be reloaded)
2) Asynchronous request (portion DOM will be updated without reloading page)

benefits:
- we can reaload only data without loading whole web page
- we can send the data to the server in async mode
- seemless experience for end user



 1) add jquery dependency in pom.xml

 	<dependency>
		    <groupId>org.webjars.bower</groupId>
		    <artifactId>jquery</artifactId>
		    <version>3.5.1</version>
	</dependency>
		
 2) Include jquery.min.js file in our html page in head tag
	
	<script src="https://code.jquery.com/jquery-3.5.1.min.js"></script> 

 3) write ajax logic to send async request to serve
	<script >
		
		$(document).ready(function() {
		
			$("#countryName").on("change",function(e) {
				$.ajax({
					type: "GET",
					url:"/cmsg",
					data:{ 
						countryName: $("#countryName").val()
					},
					success : function(data){
						$("#dropDownDiv").html(data);
					}
					
				
				});
			});
			
			$("#submitBtn").click(function(e) {
				var name = $("#name").val();
				$.ajax({
					 type: "GET",
				      url: "/msg",
				      data: {
				        name : $("#userName").val(),
				      },
				      success: function(result) {
				        $("#msgDiv").html(result)
				      },
				      error: function(result) {
				        alert('error');
				      }
				});
			});
		});
	</script>
