Linux Commands
==============

whoami : Displays logged in user calender 
date : prints todays date
cal : print current month calendar
mkdir : create new directory 
pwd : display present working directory 
rmdir : remove empty directory 
cd: change directory 
ls: list files 
touch : to  create empty file
cat : create file with content and display file content 

	[ec2-user@ip-172-31-38-130 ~]$ cat > m1.txt
	hi this is m1 file        : ctrl+d
	[ec2-user@ip-172-31-38-130 ~]$ cat m1.txt
	hi this is m1 file

	cat > filename : create file with data( we will loose old data)
	cat >> filename : append the data at the bottom
	cat filename  : display file content

rm : it is used to remove file 
mv : To rename file / directory 
cp : to copy data from one file to another file 
wc : word count (lines, words, characters)
head : gives first 10 lines of file
	$ head -n 20 <filename> (gives first 20 lines)
	$ tail -f <filename>  (on-growing data)

tail : give last 10 lines of file
	$ tail -n 20 <filename> (gives last 20 lines)

How to run Spring -boot application in Linux :
==============================================

1) install git : $ sudo yum install git 
2) install maven : $ sudo yum install maven 
 
Note : when we install maven java install automatically because maven require java(mostly java 17 )

1) clone git repo (try with dailyPractiseSBMS/23-WebMVC-App1/)

2) navigate into project directory and package application using maven (first try with project having web page and not having any  DB)
	$ mvn clean package 

	note : if we get error while executing above command then use 
	=> $ mvn clean package -DskipTests (it ignore test class is present or not )

3) then go to target folder 
	$ cd target 
	note : verify jar file creation in target directory 
	$ ls -l  
4) Run jar file using below command
	$ java -jar target/jar-file-name

note : check port number of embedded server (default : 8080)   {we use 8081 in project}

5) go to EC2 VM security group -> edit inbound rules -> enables 8081 port number 

6) Access our REST API in browser

	url http ://ec2-public-ip:8080/

Types of IP's in AWS :
======================

1) private IP -> fixed ip for internal communication, we can't use outside   
2) public IP  -> dynamic IP (change if you restart the server )  and it is used to access resources outside 
3) Elastic IP -> it is fixed public ip - it is commercial (charges applicable )

NOTE : To use  elastic IPs first we need allocated elastic ip then we have to associate elastic ip to ec2 in instance.


1) EC2 service is used to create virtual machine 
2) AMI (Amazon machine Image - configuration required for instance )
3) Instance Type ( t3.micro - free tier eligible -1 year - monthly 750 hr)
4) Key pair (public and private keys)
5) VPC (isolated network ) - default vpc
6) security group (inbound rules and outbound rules)
7) EBS volume (Elastic block storage - 8 GB for Linux)

Note : One key-pair we can use for multiple EC2 instances
Note : One security group we can use for multiple Ec2 instances

8) Types of IP's (public ip , private ip , elastic ip )

 IAM 
=====
	Note : devOps people are responsible for creation of IAM account .

-> Identity and access management 
-> It is used to create users, user groups and policies
-> when we sign up in AWS, by default we will get root account.
-> root account is very powerful account, we can access everything in aws using root account.

	Note: for team members, root account credentials will not be shared 
-> for every team member, IAM account will be created.
-> for daily activities in AWS cloud, we will use IAM accounts only.
-> as root account is powerful account, we need to provide high security for root account.
-> to provide high security for root account we can use MFA(multi factor authentication )

	Note: we can use google authenticator app to provide MFA for root account.
