------------------------------------

DAY 3 — CSS Basics: Selectors, Box Model, Typography
------------------------------------------------------
Concepts:

  - Specificity and the cascade
  - Box model: margin, border, padding, content
  - Display: block, inline, inline-block, none
  - Typography: font-family, font-size, line-height, letter-spacing

================================================================================
COMMON MISTAKES & HOW TO AVOID THEM
================================================================================

JavaScript:
  - Mutating state directly in React (always return new objects/arrays)
  - Not handling Promise rejections
  - Using var instead of const/let
  - Confusing undefined with null

React:
  - Using index as key in dynamic lists (use unique IDs)
  - Fetching data without cleanup (memory leaks)
  - Putting everything in one giant component (break it up)
  - Calling hooks inside conditions or loops
  - Not wrapping objects/arrays in useMemo when passed as props

TypeScript:
  - Using any instead of proper types
  - Ignoring TypeScript errors with @ts-ignore without understanding why
  - Not using strict mode

General:
  - Copying code without understanding it
  - Skipping error handling
  - Not writing meaningful commit messages
  - Not testing edge cases (empty arrays, null responses, network errors)
