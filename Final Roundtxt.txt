“I worked on the Integrated Data Hub platform where upstream banking systems sent transaction and customer data files. For example, if the core banking system generated a daily transaction file containing account numbers, transaction amounts, and timestamps in a legacy format, our microservices validated the records, converted the data into a standardized format, enriched it with customer and branch information, and then forwarded it to downstream systems like reporting, fraud detection, analytics, and compliance applications. We used Kafka for real-time event processing, Redis for faster access to frequently used reference data, and Autosys for scheduling batch jobs that handled large-volume nightly file processing.”
