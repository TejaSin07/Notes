NOTE::
======

Feature branches are merged into develop (or QA/integration branch). 
When code is release-ready, a release branch is created from develop for UAT/testing and stabilization fixes. 
After UAT passes, the release branch is merged into main, and main becomes the single source of truth for production deployment. 
Finally, release fixes are merged back into develop to keep branches synced.
